# ربات تلگرامی مدیریت و فروش 3X-UI

ربات فروش و مدیریت سرویس‌های Xray / 3X-UI با رابط کاربری ساده برای کاربران عادی و زیرساخت بهینه:

- **Python 3 + aiogram 3.x** (کاملاً async)
- **دیتابیس SQLite** با حالت WAL و ایندکس‌گذاری بهینه روی تمامی کوئری‌های پرتکرار
- **پشتیبانی از پروکسی SOCKS5** (اختیاری، مناسب سرورهای ایران برای اتصال به API تلگرام و پنل)
- **اتصال به پنل 3X-UI صرفاً با API Token** (`Authorization: Bearer ...` بدون نیاز به یوزرنیم/پسورد پنل)
- **ابزار خط‌فرمان اختصاصی `vpn-bot`** برای کنترل کامل سرویس، بکاپ، بازیابی و بررسی سلامت
- **سرویس `systemd`** (`vpnbot.service`) با ری‌استارت خودکار در صورت کرش یا ریبوت سرور

## نصب سریع

```bash
sudo bash install.sh
```

## مدیریت با ابزار `vpn-bot`

```bash
vpn-bot           # منوی تعاملی مدیریت
vpn-bot start     # شروع سرویس
vpn-bot stop      # توقف سرویس
vpn-bot restart   # ری‌استارت سرویس
vpn-bot status    # وضعیت سرویس systemd
vpn-bot logs      # مشاهده لاگ زنده
vpn-bot health    # بررسی سلامت ربات، توکن پنل، پروکسی SOCKS5 و دیتابیس
vpn-bot backup    # بکاپ کامل از کد، .env و دیتابیس
vpn-bot restore   # بازیابی از بکاپ
```
